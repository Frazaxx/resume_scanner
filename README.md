\# 📝 Resume Scanner



A lightweight resume analysis tool built using \*\*Python, HTML, and CSS\*\*.



Resume Scanner analyzes a resume and provides a quick overview of its structure, keywords, skills, contact information, and other important elements.



\## 🚀 Features



\- 📊 Resume score from 0–100

\- 📝 Word and character count

\- 🔍 Keyword detection

\- 🧠 Skill detection

\- 📂 Resume section detection

\- 📧 Email detection

\- 📞 Phone number detection

\- ⚡ Action verb detection

\- 💡 Personalized improvement suggestions

\- 📄 `.txt` resume upload

\- 🌙 Modern dark-themed interface

\- 🐍 Python standard library only



\## 🛠️ Technologies



\- Python

\- HTML

\- CSS



No Flask, Django, React, Bootstrap, or other frameworks are used.
